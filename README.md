# 안경원 고객관리 시스템 - 1단계 MVP

## 포함된 기능
- 상단 버튼바: 고객검색(F6)·신규고객(F5) 작동. 일반판매(F3)/A/S전표/처방전(F11)/AI 고객데이터 분석은 원본과 동일한 위치에 버튼만 배치된 자리표시자(다음 단계 구현 예정)
- 고객 등록/수정, 검색 모달(F6) — 이름/전화번호 뒷자리 검색, 동명이인 목록 확인 후 선택
- 검색 모달에서 고객 선택 시 과거 방문 날짜 목록(초록 박스)이 뜨고, 날짜 클릭 시 그날 검안+매출 기록을 바로 확인 가능
- 신규 검안정보: 안경(굴절) 13항목 + 콘택트렌즈 7항목 (OD/OS), 처방 메모
- 매출정보: 상품 7줄 입력 그리드 (분류/바코드, 브랜드, 상품명, 색상, 수량, 단가) — 수량×단가 입력 시 매출합계 자동 계산
- 결제정보: 현금/카드/상품권 체크박스+금액, 미수, 할인, 현금영수증, 카드구분, 상품권구분, 방문일자/방문주기, 완성일자, 담당자/판매자, 매출메모
- **저장(F10) 버튼 하나로 고객정보 + 검안정보 + 매출/결제까지 한 번에 저장** (이전 버전의 "따로 저장해야 하던" 문제 해결)
- **방문 날짜 불러오기/수정**: 오른쪽 "방문내역" 목록이나 검색 모달의 방문 날짜를 클릭하면 그날의 검안+매출+결제 기록이 화면에 그대로 불려와서 수정할 수 있음. 이 상태에서 저장(F10)을 누르면 새로 만들지 않고 그 기록을 업데이트함
- 검색 모달에서 방문 날짜를 클릭하면 매출정보(상품 목록)와 결제 요약(매출합계/현금/카드/미수/담당자 등)까지 모달 안에서 바로 확인 가능
- 취소(F12): 검안/매출/결제 입력칸만 초기화 (고객정보는 유지)
- 과거 검안정보 이력 조회 (최신순, 좌우 스크롤, 매출합계 포함)
- 방문내역 목록 (오른쪽 패널)

## A/S전표 (수리 접수)
상단 "A/S전표" 버튼으로 열리는 접수 창에서 고객정보 · A/S내역(파손부위/내용) · 비용(선금/잔금/합계)을
입력하고 저장(F10)하면 서버에 저장됩니다. "A/S 목록" 탭에서 고객명/전화번호/고객번호로 검색하고,
접수일자·완성일자 기간으로도 좁혀볼 수 있습니다. 목록에서 행을 클릭하면 그 기록이 전표 화면에 불려와서
수정 후 다시 저장할 수 있습니다. (인쇄 기능은 아직 자리표시자)

## 아직 자리표시자(placeholder)인 기능 — 다음 단계에서 하나씩 구현
- 처방전(F11) 출력, AI 고객데이터 분석, A/S전표 인쇄
- 특이사항(F2)/가족목록(F4) 버튼과 가족 목록 테이블
- 택배신청/배송확인
- (제외 대상, 원본에도 X 표시됨) 문자메세지, 자동주문, 애니아이몰, 양안시, 이전매출, 증정입력, 포인트, 카드번호, 전화번호(유선), 발송여부

기존 `optical.db`가 있다면 문제없이 그대로 쓰셔도 되지만, 혹시 이상 동작이 있으면 삭제 후 재실행해보세요.

## 저장 버그가 고쳐진 이유
이전 버전은 "고객 저장" 버튼과 "검안정보 저장" 버튼이 분리되어 있어서,
고객을 먼저 저장하지 않으면 검안정보가 어느 고객 것인지 연결되지 않아 저장되지 않는 문제가 있었습니다.
지금은 **저장(F10) 버튼 하나가 내부적으로 "고객 저장/수정 → 검안+매출+결제 저장"을 순서대로 함께 처리**하도록 통합했습니다.
홍길동을 새로 입력하고 모든 값을 채운 뒤 저장(F10)을 누르면, 고객 등록과 검안/매출 기록이 한 번에 저장되고
고객검색(F6)으로 다시 불러오면 그대로 조회됩니다.

## 폴더 구조 (중요)
아래 4개 파일이 **같은 폴더 안에** 나란히 있어야 합니다 (하위 폴더 없음):
```
optical_app/
├── main.py
├── database.py
├── index.html
└── requirements.txt
```

## 실행 방법 (Windows)

1. `optical_app` 폴더를 파일 탐색기에서 열고, 주소창을 클릭해 `cmd` 입력 후 Enter (그 폴더 위치에서 명령 프롬프트가 열립니다)

2. 필요한 패키지 설치
   ```
   python -m pip install -r requirements.txt
   ```

3. 서버 실행 (uvicorn 명령이 안 먹히면 python -m uvicorn 으로)
   ```
   python -m uvicorn main:app --reload
   ```
   "Uvicorn running on http://127.0.0.1:8000" 메시지가 뜨면 이 창은 닫지 말고 그대로 두세요.

4. 브라우저에서 아래 주소로 접속 (index.html 파일을 직접 더블클릭하면 안 됩니다)
   ```
   http://localhost:8000
   ```

5. 데이터는 같은 폴더에 `optical.db` 파일로 자동 저장됩니다 (SQLite).
   이 파일을 백업하면 전체 데이터가 백업됩니다.
